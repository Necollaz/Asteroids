# Asteroids

2D clone of the original Asteroids game made as a Unity programmer test assignment.

## Unity Version

Unity 2022.3.9f

## Project Goal

The goal is to implement a 2D Asteroids-style game with custom physics, Zenject-based architecture, SignalBus, MVVM UI, object pooling, JSON configs, Firebase Analytics, and an ads adapter.

## Current Status

Project preparation stage:
- Unity project created
- Git repository initialized
- Basic folder structure prepared
- Assembly Definitions added
- Zenject connected
- UniTask connected
- Firebase SDK preparation started
- Ads service interface prepared

## Main Requirements

- C#
- Unity 2022.3.9f
- 2D gameplay
- Custom physics, no Unity Physics for gameplay movement/collisions
- Zenject
- SignalBus
- MVVM
- UniTask instead of coroutines
- Object Pool
- Factory-based object creation
- JSON configs
- Firebase Analytics
- Ads adapter
- Assembly Definitions
